## Guide Format

Each guide includes:

- **Introduction** — What problem this solves and when to use it
- **Prerequisites** — Required skills and setup
- **Step-by-step walkthrough** — Commands with explanations
- **Sample output** — Real example of what you'll produce
- **Variations** — How to adapt for similar use cases

## Suggest a Guide

Have a workflow pattern you'd like documented? Open an issue on [GitHub](https://github.com/memorysaver/looplia-core/issues) with:

1. The use case you want to accomplish
2. Which skills you think would be involved
3. Any specific challenges you've encountered

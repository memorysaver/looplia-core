The `skill` command installs and manages individual skills from the catalog.

## Usage

```bash
looplia skill <subcommand>
```

## Subcommands

### add

Install a skill from the catalog to your workspace.

```bash
looplia skill add <name>
```

**Examples:**

```bash
looplia skill add xlsx
looplia skill add frontend-design
```

<Aside type="note">
Skills are installed via JIT (just-in-time) cloning from their source repository.
</Aside>

### search

Search the skills.sh registry for skills matching your query.

```bash
looplia skill search <query>
```

**Examples:**

```bash
looplia skill search "pdf"
looplia skill search "excel spreadsheet"
```

In interactive mode (TTY), you'll be prompted to select skills to install:

```
Found 3 skill(s):

─────────────────────────────────────────────────────────────────────────
  #  NAME                 OWNER/REPO                    DESCRIPTION
─────────────────────────────────────────────────────────────────────────
  1  pdf                  anthropics/skills             PDF manipulation...
  2  xlsx                 anthropics/skills             Excel processing...
  3  docx                 anthropics/skills             Word documents...
─────────────────────────────────────────────────────────────────────────

Enter number(s) to install (comma-separated), or 'q' to quit: 1,2
```

<Aside type="tip">
In non-interactive mode (piped input), search displays results without prompting. Use `looplia skill add <name>` to install specific skills.
</Aside>

### list

List skills in your workspace.

```bash
# List installed skills
looplia skill list

# List all available skills from catalog
looplia skill list --available
```

### info

Display detailed information about a skill including its source, description, and usage.

```bash
looplia skill info <name>
```

**Example:**

```bash
looplia skill info xlsx
```

### remove

Remove an installed skill from your workspace.

```bash
looplia skill remove <name>
```

### update

Update a third-party skill by pulling the latest changes from its source repository.

```bash
looplia skill update <name>
```

## Workflow Skills Declaration

Workflows can declare which skills they need using the `skills:` field in frontmatter:

```yaml
---
name: document-processor
skills:
  - xlsx
  - pdf
  - docx
steps:
  - skill: xlsx
    input:
      file: "{input.spreadsheet}"
---
```

When you declare skills in your workflow:

- **Only declared skills** are loaded into the Claude Code context
- **Core skills** are always loaded automatically
- This **reduces context window usage** significantly

<Aside type="tip">
Without the `skills:` declaration, all installed skills are loaded. For large workspaces, explicitly declaring skills improves performance.
</Aside>

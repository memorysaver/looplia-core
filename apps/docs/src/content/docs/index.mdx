<div class="section-header">
  <h2>Why Looplia?</h2>
  <p>A new approach to AI workflows — skills as first-class citizens, not rigid code.</p>
</div>

<CardGrid>
  <Card title="Skills-First Architecture" icon="puzzle">
    Workflows declare **skills + missions** in natural language. Claude determines the best approach. No rigid agent definitions required.
  </Card>
  <Card title="Workflow-as-Markdown" icon="document">
    Define workflows in readable **YAML frontmatter + Markdown**. Version control friendly, human-readable, easy to share and modify.
  </Card>
  <Card title="Build with AI" icon="rocket">
    Describe what you want in plain English. **looplia build** generates a complete workflow definition automatically.
  </Card>
  <Card title="Sandbox Isolation" icon="seti:folder">
    Each run creates an **isolated sandbox** with inputs, outputs, and logs. Pause and resume anytime with **--sandbox-id**.
  </Card>
</CardGrid>

<div class="section-header">
  <h2>How It Works</h2>
  <p>From content to structured output in three steps.</p>
</div>

<div class="workflow-diagram">
<pre>{`┌─────────────────┐    ┌─────────────────┐    ┌─────────────────┐
│  `}<span class="highlight">media-reviewer</span>{` │───▶│  `}<span class="accent">idea-synthesis</span>{` │───▶│  `}<span class="highlight">writing-kit</span>{`    │
│                 │    │                 │    │  -assembler     │
└─────────────────┘    └─────────────────┘    └─────────────────┘
        │                      │                      │
        ▼                      ▼                      ▼
   summary.json          ideas.json          writing-kit.json`}</pre>
</div>

```yaml title="workflows/writing-kit.md"
---
name: writing-kit
version: 1.1.0
description: Transform content into structured writing kit

steps:
  - id: summary
    skill: media-reviewer
    mission: |
      Deep analysis of content to extract key themes.
      Extract minimum 3 verbatim quotes, at least 5 key points.
    input: ${{ sandbox }}/inputs/content.md
    output: ${{ sandbox }}/outputs/summary.json

  - id: ideas
    skill: idea-synthesis
    mission: Generate creative hooks, angles, and questions.
    needs: [summary]
    input: ${{ steps.summary.output }}
    output: ${{ sandbox }}/outputs/ideas.json

  - id: writing-kit
    skill: writing-kit-assembler
    mission: Assemble final writing kit with outline.
    needs: [summary, ideas]
    final: true
---
```
